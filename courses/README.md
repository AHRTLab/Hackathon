# Courses

One JSON file per course, listed in `index.json`. You can add a course without touching any code.

| Field | Meaning |
|---|---|
| `id`, `name` | Short id (used in logs) and display name |
| `arena.size` | `[x, y]` full size in metres, centred on the origin. Walls are added around it |
| `arena.wall_height`, `arena.wall_thickness` | Optional, defaults 0.4 m / 0.1 m |
| `start` | `{x, y, yaw}`: start pose (m, m, rad). `yaw` 0 faces +x |
| `obstacles[]` | `{"type":"box","pos":[x,y],"size":[sx,sy,sz],"yaw":rad}` or `{"type":"cylinder","pos":[x,y],"radius":r,"height":h}`. Sizes are **full** dimensions, and objects sit on the floor. Optional `rgba` |
| `gates[]` | `{"left":[x,y],"right":[x,y]}` post positions, in the order they must be taken. Drive through with `left` on your left (crossing backwards doesn't count). Posts are 0.6 m tall and collidable |
| `finish` | `{"type":"line","left":[x,y],"right":[x,y]}`, or `{"type":"dock","center":[x,y],"yaw":rad,"size":[sx,sy],"tol_m":0.15,"tol_deg":10,"hold_s":1}` (stop inside: centre within `tol_m`, heading within `tol_deg`, speed ~0, held `hold_s`), or `null`. A course with gates but no finish ends at the last gate |
| `path` | Optional `[[x,y],...]` waypoints for `autopilot_gates.py` (e.g. through a corridor). Not shown to drivers |
| `time_limit` | Seconds before DNF, or `null` |
| `speed_caps` | `{"v":1.0,"w":2.0}` lowers the protocol limits for this course, or `null` |

Scoring (shown at the finish and logged): `score_time = elapsed + 5 s × collisions + 10 s × missed gates`.
The clock starts at the robot's first movement after a reset. Obstacles lower than about 0.27 m are below
the lidar plane, so keep walls and obstacles at least 0.3 m tall.

L1–L3 are generated by `web/scripts/make_courses.py`. Edit that script and re-run it, or hand-edit the
JSON. `npm test` checks that every course compiles, starts collision-free, and that the reference
autopilot can complete it.
